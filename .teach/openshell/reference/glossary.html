Glossary

Short definitions used across this course. If a lesson uses a term, it means this.

People and products

OpenShell. NVIDIA’s open-source agent sandbox platform. The thing that actually runs isolated agent environments. Repo: NVIDIA/OpenShell.

OpenShell gateway. The API the platform exposes. Dashboard talks to this, not to Kubernetes Sandbox objects, once the epic is done. Today that talk is gRPC; upstream is moving toward openshell-sdk-go.

openshell-dashboard. The upstream admin UI: React + PatternFly 6 + a Go BFF. Repo: Gkrumbach07/openshell-dashboard.

odh-dashboard. The Open Data Hub / RHOAI web UI monorepo you are in now. It is the host that will load OpenShell as a plugin.

agent-ops. Current odh package (packages/agent-ops) that lists/creates agents by reading Kubernetes Sandbox CRs. This path is what the epic removes after cutover.

How the UI is plugged in

Host. The main dashboard app in frontend/. It owns chrome (nav, auth session, feature flags) and loads plugins.

Remote / federated module. A package under packages/ that webpack Module Federation loads at runtime. It exposes ./extensions (and sometimes ./extension-points).

Module Federation (MF). Webpack feature: the host fetches another app’s JavaScript at runtime and runs it in the same page, sharing one copy of React. See docs/module-federation.md.

remoteEntry.js. The file the host loads to find a remote’s modules. Served under /_mf/{name}/remoteEntry.js.

Extension. A small JSON-like object a plugin registers: “here is a route”, “here is a nav link”, “here is a feature area”. The host already knows how to render those types.

Slot. Upstream’s name for an extension point inside OpenShell pages so the host can inject extra UI (a button, a tab). The epic requires at least one slot wired and documented.

Singleton. “Only one copy of this library in the page.” React and PatternFly must be singletons or you get two Reacts and the UI breaks.

How API calls move

BFF (Backend for Frontend). A small Go HTTP server that sits next to the UI. The browser talks REST to the BFF. The BFF talks to the real backend (Kubernetes today; OpenShell gateway tomorrow).

Host proxy. odh-dashboard’s backend forwards browser calls like /_bff/openshell/api/... to the module BFF as /api/.... Config lives in the package’s module-federation.proxy array.

Token relay. Upstream BFF does not log you in. It copies a bearer token from a header onto every gateway call. The gateway checks the JWT. See ADR 0002.

x-forwarded-access-token. Header odh already uses to pass the logged-in user’s token to module BFFs when authorize: true.

Domain objects

Sandbox CR. A Kubernetes Custom Resource agents.x-k8s.io/v1beta1/sandboxes. agent-ops lists ones labeled openshell.ai/managed-by=openshell.

Workspace. OpenShell-native grouping (members + roles). Not the same thing as a Kubernetes namespace, even if they sometimes line up in a deployment.

Write-only secrets. Provider credentials are sent to the gateway; the UI must never get the secret values back — only key names.

Adhered to by every lesson in this workspace. Update here, not by inventing new meanings in a lesson.
