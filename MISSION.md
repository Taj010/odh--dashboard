# Mission: Understanding the ODH Dashboard Codebase

## Why
To become a confident contributor to the Open Data Hub Dashboard repository. The user is new to professional software development beyond JS/React fundamentals, and needs to understand the codebase's architecture, tooling, and domain concepts well enough to pick up issues, write code that passes review, and not feel lost.

## Success looks like
- Can navigate the monorepo and know where to find things (which folder, which package)
- Understands the key technologies beyond JS/React: TypeScript, PatternFly, Module Federation, monorepo tooling
- Knows what Kubernetes/OpenShift are at a level sufficient to understand what the UI is managing
- Can run the dev server, write a component, run tests, and open a PR that follows the project's conventions
- Understands the domain vocabulary: projects, workbenches, pipelines, model serving, etc.

## Constraints
- Prior knowledge: JavaScript and React basics only
- No prior exposure to TypeScript, Kubernetes, monorepos, or enterprise UI patterns
- Learning happens in short sessions alongside work

## Out of scope
- Go / BFF development (backend-for-frontend services) — revisit later once frontend is solid
- Kubernetes operator / controller code
- CI/CD pipeline configuration (Tekton)
- Deployment and production operations
