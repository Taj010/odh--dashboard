# TypeScript basics introduced via JS comparison

The user was taught TypeScript through side-by-side JS/TS comparisons using real codebase examples (string.ts, ExternalLink.tsx, types.ts). Covered: annotations, function types, `type`/`interface`, enums, union/intersection types, generics (conceptually), `?.`, `??`, `as const`. All examples grounded in files the user will actually encounter. Next zone: applying this by reading real components, or learning PatternFly (the UI layer that uses these types).
