# Selected gateway is part of the address

The screen shows one gateway at a time, and a person can be logged in to several gateways at once. The address names the gateway they are viewing. The OpenShell login stays in memory and is never put in the address. A reload keeps the same gateway selected and asks for that gateway's login again. Keeping the selection only in memory was the alternative; a reload would then forget which gateway the person meant, including after the login redirect.
