# Logout is not Disconnect or account switch

A gateway has three ways to end its OpenShell login. Disconnect drops the login on this page only and leaves the identity-provider session alone. Logout also asks the identity provider to end that session, and does not start a new login. Account switch does that provider logout when it can, then asks the person to log in again so they can pick a different account. If the provider cannot log out, the login on this page is still dropped, and the page says the provider may still remember the account. Each action affects the selected gateway only. Treating logout as "the dashboard user left" was the alternative. That would hide the case where the same dashboard user wants the provider to forget the OpenShell account without choosing a new one.
