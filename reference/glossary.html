Glossary

Quick-reference definitions for terms you'll encounter in the ODH Dashboard codebase. Updated as new lessons introduce new vocabulary.

Project & Product

ODH (Open Data Hub)
The open-source upstream project this repo belongs to.
RHOAI (Red Hat OpenShift AI)
Red Hat's supported product built from ODH. Same codebase, different packaging and branding.
Dashboard
The web application this repo builds — a UI for managing data science resources on Kubernetes.

Infrastructure

Kubernetes (K8s)
An open-source system for running and managing containerized applications across servers.
OpenShift
Red Hat's distribution of Kubernetes with extra developer and enterprise features.
Resource (K8s)
A JSON/YAML object describing a desired state in K8s. Has apiVersion, kind, metadata, spec, status.
Namespace
A Kubernetes isolation boundary — like a folder for resources. Each Data Science Project is a namespace.
CRD (Custom Resource Definition)
A way to extend Kubernetes with new resource types (e.g., "Notebook", "InferenceService").
RBAC (Role-Based Access Control)
The system that controls who can do what in Kubernetes.
SAR / SSAR
SubjectAccessReview / SelfSubjectAccessReview — API calls to check "can this user do X?"

Codebase

Monorepo
A single Git repository containing multiple related packages.
npm workspaces
npm's built-in feature for managing multiple packages in one repo, sharing node_modules.
Turbo
A build tool that runs tasks (build, test, lint) across monorepo packages efficiently with caching.
Module Federation
A webpack feature that lets packages load their code into the main app at runtime (not build time).
BFF (Backend For Frontend)
A small backend service written in Go that serves a specific feature package's API needs.
PatternFly (PF)
Red Hat's open-source UI component library — provides buttons, tables, modals, layouts, etc.
K8sResourceCommon
A TypeScript type representing the base shape of any Kubernetes resource object.

Domain (Data Science)

Data Science Project
A workspace in the dashboard. Maps to a Kubernetes namespace. Contains workbenches, pipelines, etc.
Workbench
A running Jupyter notebook environment for writing and experimenting with code.
Pipeline
An automated multi-step workflow (e.g., "clean data → train model → evaluate").
Model Serving
Deploying a trained ML model so other applications can query it for predictions.
Model Registry
A catalog of trained models with version history and metadata.
Connection
Saved credentials for external services (S3 buckets, databases, API endpoints).
Hardware Profile
A predefined set of compute resources (CPU, memory, GPU) for running workbenches.
Notebook Controller
A Kubernetes controller that manages the lifecycle of notebook (workbench) pods.

TypeScript

Type annotation
A label after a variable or parameter name: name: string. Tells TS what type a value must be.
Type inference
TS figuring out the type automatically from the value: const x = 5 is inferred as number.
type
A keyword to define an object shape or union: type Props = { text: string }.
interface
Another way to define object shapes. Nearly interchangeable with type in this codebase.
enum
A set of named constants: enum Status { Active, Inactive }. Used instead of raw strings.
Union type (|)
"This OR that": string | number means the value can be either type.
Intersection type (&)
"This AND that": A & B means the value has all properties from both types.
Generic (<T>)
A type placeholder filled in by the caller: React.FC<MyProps> fills in the props type.
?. (optional chaining)
Safely access a property that might not exist. Returns undefined instead of crashing.
?? (nullish coalescing)
Provide a fallback for null/undefined: value ?? 'default'.
as const
Makes object values readonly with narrow literal types instead of broad string.
void
Return type meaning "this function returns nothing."
React.FC<Props>
A React Function Component typed with a specific props shape.

PatternFly (PF)

PatternFly (PF)
Red Hat's open-source UI component library. Provides pre-built React components, design tokens, and layout systems.
Design token
A CSS variable defined by PF (e.g., --pf-t--global--spacer--md) that stores a design value. Adapts to dark mode automatically.
PF utility class
A CSS class from PF (e.g., pf-v6-u-mb-lg) that applies a single style. Used when component props aren't enough.
Component variant
A pre-defined visual style for a PF component, set via a prop: <Button variant="danger">.
Layout component
A PF component for arrangement: Stack, Flex, Grid, Split, Gallery. Use instead of custom CSS flex/grid.
Composable table API
PF's table pattern using individual Table, Thead, Tbody, Tr, Th, Td components.
@patternfly/react-core
The main PF package. Contains Button, Modal, Alert, Flex, Stack, TextInput, and most other components.
@patternfly/react-table
PF package for table components (Table, Thead, Tbody, Tr, Th, Td).
@patternfly/react-icons
PF package providing hundreds of icons as React components (e.g., SearchIcon, ExternalLinkAltIcon).
Wrapper component
A project-specific component that wraps a PF component with extra behavior (e.g., DashboardModalFooter, Table from components/table/).

Development

TypeScript
A superset of JavaScript that adds static type checking. All code in this repo is TypeScript.
Jest
A JavaScript unit test framework. Tests use describe/it/expect.
Cypress
An end-to-end testing tool that runs a real browser and interacts with the app like a user.
ESLint
A tool that checks your code for style and potential errors (linting).
Prettier
A code formatter that enforces consistent formatting (indentation, quotes, etc.).
Husky
A tool that runs scripts (like linting) automatically when you commit code.
oc (OpenShift CLI)
Command-line tool to log in to an OpenShift cluster and manage Kubernetes resources. Local backend needs a valid oc login session.
.env.local
Untracked local config (copied from .env.local.example). Holds values like OC_PROJECT and optional login helpers. Never commit it.
Hot reload
Dev-server behavior: save a frontend file and the browser updates without a full manual refresh.
start:dev:ext
Frontend script that runs the UI against an external cluster backend (EXT_CLUSTER=true). Usual path for UI-only work.
Dev feature flags
Append ?devFeatureFlags to the dashboard URL to toggle feature flags for your browser session only.
Extension / plugin
A small declaration the app collects at runtime (e.g. app.route, app.navigation/href) instead of hardcoding every feature into one file.
app.route
Extension type that maps a URL path to a lazily loaded page component. Declared in plugins/extensions/routes.ts (and packages).
ApplicationsPage
Shared page shell from @odh-dashboard/ui-core: title, description, loading spinner, error, and empty states. Most screens wrap their body in it.
*Page.tsx
Convention for a screen component: call a data hook, pass results into ApplicationsPage, render body UI as children.
*Routes.tsx
Convention for nested React Router routes inside one feature (list / create / edit).
useWatch* / data hook
A React hook that loads (and often watches) API/cluster data and returns a tuple like [data, loaded, loadError, refresh].
