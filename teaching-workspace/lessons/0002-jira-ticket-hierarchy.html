What Each Level Means

Level Prefix Scope Who Writes It Example
Strategy RHAISTRAT Multi-release vision Product/PM "Agent Hub in RHOAI Dashboard"
Feature RHAISTRAT or RHAIRFE One release deliverable Product/PM + Eng Lead "Deploy agents from Dashboard"
Epic RHOAIENG Logical grouping of stories Engineering "Deploy BFF" or "Deploy UI"
Story RHOAIENG One implementable unit Engineering "Add deploy button to list page"

Status: ⚠️ BLOCKED on backend dependency

What it does: Administration UI for OpenShell (workspaces, policies, credentials).

Key concepts:

  • Workspace — Tenant isolation boundary (who can access what sandboxes)
  • Policy — Security rules (network policies, allowed binaries, filesystem access)
  • Provider — Inference endpoints and credentials (API keys for LLMs)
  • Interceptor — Webhooks that enforce default policies across all sandboxes

The Critical Blocker

Track 3 is hard-gated on a backend that doesn't exist yet:

RHAISTRAT-1752 — RHOAI must deploy an OpenShell gateway

Status: On-hold upstream, undated
Impact: The Admin UI has nothing to administer. You can build the UI, but it won't work in a real RHOAI install until the gateway exists.

What this means for you:

  1. You can develop against a self-hosted or HyperShell gateway (for dev/demo)
  2. The feature cannot ship until the backend lands
  3. Don't commit to a specific release date — it tracks the backend

Reading a Jira Ticket: What to Look For

When you open a Jira ticket, here's what matters:

Section What It Tells You
Summary One-line description of what's needed
Description / Goal The "why" — what problem this solves
In Scope / Out of Scope Exactly what you should and shouldn't build
Acceptance Criteria How to know when you're "done" (your checklist)
Dependencies What must exist before you can start/finish
Child Issues / Delivery Epics The breakdown of actual work
Status New / In Progress / Blocked / Done

How Dependencies Work

Dependencies tell you what blocks your work:

Dependency Types: ───────────────────────────────────────────────────── "Blocked by" → You CANNOT start until this is done "Depends on" → You can start, but can't finish/ship "Related to" → Nice to know, doesn't block you

From RHAISTRAT-2467's dependencies:

Dependency Status Impact
RHOAI-deployed gateway (1752) 🔴 BLOCKED Hard blocker — cannot ship without it
Go SDK (2245) 🟡 Needed Can use hand-rolled stubs, but SDK is cleaner
Double-auth spike 🟡 In Progress Embedded RHOAI experience can't auth without it

Quiz: Check Your Understanding

1. What does "hard-gated" mean for a feature?

  • It's very difficult to implement
  • It requires special permissions
  • It cannot ship until a dependency is met
  • It's locked and can't be changed

2. What is the relationship between an Epic and a Story?

  • They are the same thing with different names
  • An Epic groups related Stories together
  • A Story groups related Epics together
  • Epics are for backend, Stories are for frontend

3. Why is Track 3 (Admin UI) blocked?

  • The OpenShell gateway doesn't exist in RHOAI yet
  • The frontend framework isn't ready
  • Track 1 and Track 2 must finish first
  • There's no designer assigned
