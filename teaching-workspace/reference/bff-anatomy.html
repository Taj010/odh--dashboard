Print this. Full lesson: Lesson 9. CR code: packages/agent-ops/bff/. Recipe: .claude/rules/bff-go.md.

Sandwich

  • Bread / shell — port, health, logs, CORS, read token header. Copy the pattern.
  • Filling / domain — backend client, OpenAPI, permission rules. Do not merge CR with OpenShell.

Three “shares”

  1. Copy the pattern — proxy block, flags, health.
  2. Reuse the library — import/decorate OpenShell (Lesson 8).
  3. Do not merge fillings — no shared SAR, K8s client, or single OpenAPI.

One process later still means two fillings (two route trees).
