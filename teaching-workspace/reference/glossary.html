Agent Ops Glossary

Quick reference for key terms. Print this out and keep it handy.

Architecture Terms

Agent

A program that can receive instructions, think, take actions, and report results. Examples: code assistant, support bot, data analyzer.

AgentRuntime

A running instance of an agent. The AgentRuntime is what you see in the dashboard — it represents the live container with its status, endpoints, and health.

Related: Sandbox CR (1:1 mapping)

BFF (Backend-for-Frontend)

A Go server that sits between the browser and a backend. Agent-ops BFF talks to Kubernetes. OpenShell BFF talks to the gateway. The browser cannot talk to those backends directly.

See also: CR path, gateway path, one vs two BFFs

BFF shell (bread)

The parts every BFF copies: listen port, health check, logs, CORS, timeouts, reading the auth header. Same shape, different values. See BFF anatomy.

BFF filling (domain)

The parts that are unique to one product: backend client (K8s vs gRPC), OpenAPI document, handlers, permission rules (SAR vs gateway RBAC). Do not merge CR filling with OpenShell filling.

Middleware

A function that wraps an HTTP handler: run code before/after (auth, CORS, logging, panic recover). Chain: identity → CORS → handler.

Handler

The Go function for one route (e.g. list agent runtimes). Reads the request, calls a service/repository, writes JSON.

Healthcheck

A cheap GET route (usually /healthcheck) that means “this process is alive.” Kubernetes probes and contract tests hit it. Different from readiness (“can I reach the gateway?”).

Sandbox CR (Custom Resource)

A Kubernetes object that defines a secure, isolated execution environment for one agent. When you create a Sandbox CR, Kubernetes automatically creates the Pod and Service. Each Sandbox CR = one AgentRuntime.

API Group: agents.x-k8s.io/v1beta1/sandboxes

OpenAPI Spec (Contract)

A YAML file that describes the API: endpoints, parameters, request/response shapes. The frontend and BFF both follow this contract. If they disagree, the spec is the source of truth.

Location: packages/agent-ops/api/openapi/agent-ops.yaml

Module Federation

A webpack feature that lets multiple applications share code at runtime. Agent Ops is a "remote" module that gets loaded into the main RHOAI dashboard (the "host").

OpenShell Terms (Track 3)

OpenShell

A platform for running agents in governed, secure sandboxes. It has its own control plane (gateway) separate from Kubernetes. OpenShell enforces security policies and manages agent lifecycles.

Gateway

The OpenShell server that manages workspaces, policies, and sandboxes. It exposes a gRPC API. The BFF talks to the gateway via the Go SDK.

⚠️ Does NOT exist in RHOAI yet (RHAISTRAT-1752)

Workspace

An isolation boundary in OpenShell. A workspace contains sandboxes, providers, policies, and members. Think of it as a "tenant" — controls who can access what.

Policy

Security rules enforced on sandboxes: network policies, allowed binaries/paths, filesystem access. Policies use Landlock and seccomp, NOT OPA/Rego.

Provider

A registered inference endpoint with credentials (e.g., OpenAI API key, Anthropic key). The BFF strips secret values — the browser never sees actual credentials.

Interceptor

A webhook-like mechanism that enforces default policies across all sandboxes. Platform admins use interceptors to set org-wide security baselines.

CR path

Browser → host proxy /agent-ops/api → agent-ops BFF (port 8843) → Kubernetes Sandbox CRs. Tracks 1 and 2 (list/deploy). Auth uses the user’s OpenShift token plus SAR.

Opposite: gateway path

Gateway path

Browser → host proxy /_bff/openshell/api → OpenShell BFF (port 8943) → OpenShell gateway (gRPC). Track 3 admin UI. BFF is relay-only; the gateway enforces RBAC.

Opposite: CR path. Blocked on RHAISTRAT-1752

Upstream / downstream (BFF)

Upstream = OpenShell’s Go BFF, published as a module. Downstream = ODH/AgentOps consuming that module. Downstream can run it unchanged or decorate it. Not the same as “two processes in the pod.”

openshell-bff-examples

Struct embedding

Go composition: put another type inside a struct without a field name. Its methods are promoted. Downstream embeds an upstream service interface and overrides one method; the rest keep working. See Effective Go.

Decorator (Go BFF)

A wrapper that implements the same interface as the thing it wraps, then changes or extends some methods. In the examples repo, downstream’s sandbox Service decorates upstream SandboxService.

Double-Auth

The authentication flow for embedded OpenShell UI. User logs into RHOAI (primary session), then a second OpenShell-scoped token is obtained against shared Keycloak and forwarded to the gateway.

Jira Terms

Strategy (RHAISTRAT)

Multi-release vision. The big picture. Example: "Agents UI in AI Hub" spanning 3.5, 3.6, 3.7 releases.

Feature (RHAISTRAT or RHAIRFE)

One release deliverable. A significant capability that ships in one release. Example: "Deploy agents from Dashboard" (3.6).

Epic (RHOAIENG)

A logical grouping of stories. Usually split by area (BFF vs UI) or phase. Example: "Deploy BFF" or "Deploy UI".

Story (RHOAIENG)

One implementable unit of work. Usually results in 1-3 PRs. Written as "As a [user], I can [action]..."

Hard-Gated / Blocked

A feature that CANNOT ship until a specific dependency is met. Not just "nice to have" — literally impossible to ship without it.

Module Federation & Proxy Terms

Proxy

A middleman server that receives a request, modifies it (e.g., rewrites the URL path, adds auth headers), and forwards it to another server. The browser talks to the proxy; the proxy talks to the real backend. This lets you keep the backend on a different port or machine without the browser knowing.

Related: pathRewrite, authorize

pathRewrite

A proxy rule that changes the URL path before forwarding. For example, /_bff/openshell/api is rewritten to /api so the BFF doesn't need to know about the host's routing prefix.

remoteEntry.js

A JavaScript file generated by webpack/rspack that acts as the "table of contents" for a Module Federation remote. The host fetches this file to discover what components the remote module exposes.

Singleton (MF)

A Module Federation setting that ensures only one copy of a library (like React) is loaded at runtime. Without it, the host and module would each load their own copy, causing crashes.

Remote / Host

Host = the main dashboard app that loads other modules. Remote = a module that gets loaded into the host (e.g., agent-ops, model-registry, openshell). Remotes expose components via remoteEntry.js.

Spike

A time-boxed research task. No production code is written. The engineer investigates feasibility, documents findings, and recommends an approach. Example: "Can we embed OpenShell in the dashboard? What breaks?"

iframe

An HTML element that embeds an entire webpage inside another webpage, like picture-in-picture. Rejected for OpenShell because it doesn't share auth, styling, or navigation with the parent page.

SPA (Single Page Application)

A web app that loads once and then updates the page dynamically without full page reloads. React apps are SPAs. OpenShell standalone is an SPA; when embedded in the dashboard, it becomes a federated remote instead.

gRPC

A communication protocol (like HTTP but different). The OpenShell BFF uses gRPC to talk to the OpenShell gateway. You don't interact with gRPC directly — the BFF handles it. The browser only uses regular HTTP.

Sidecar

A helper container that runs alongside the main application container in the same Kubernetes pod. The OpenShell BFF runs as a sidecar to the dashboard — it has its own process but is deployed together.

Development Terms

Contract-First Development

Write the OpenAPI spec FIRST, then implement code that matches it. Prevents frontend/backend mismatch bugs.

Tech Preview (TP)

A feature that's available but not fully supported. Can have bugs, API may change. Not for production use.

GA (Generally Available)

A feature that's fully supported and production-ready. API is stable.

validate:ports

An npm script (npm run validate:ports) that checks every module's package.json for port conflicts. If two modules use the same port, the script fails. Runs automatically in pre-commit hooks and CI.

Location: scripts/validate-module-ports.js

PatternFly (PF)

Red Hat's UI component library. Provides buttons, tables, forms, etc. RHOAI uses PatternFly v6.

Docs: patternfly.org/v6/
